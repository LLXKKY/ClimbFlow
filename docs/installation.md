# ClimbFlow Installation Guide

ClimbFlow is a beta plugin for Rhino 8 on Windows.

This guide explains how to install ClimbFlow using the `.yak` package file.

## 1. Requirements

Before installing, make sure you have:

- A Windows computer
- Rhino 8 installed
- The ClimbFlow `.yak` package file for Windows and Rhino 8

## 2. Download the Package

Download the ClimbFlow `.yak` package from the official download page when it becomes available.

Save the package file to a folder on your computer.

**Important:** Make sure you are using the package intended for Rhino 8 on Windows.

## 3. Install ClimbFlow

The installation process uses drag and drop.

1. Open Rhino 8 on your Windows computer.
2. Locate the downloaded ClimbFlow `.yak` file in File Explorer.
3. Drag the `.yak` file into the Rhino window.
4. Follow any installation prompts displayed by Rhino.
5. Wait for the installation process to finish. If Rhino asks you to restart, follow the prompt.

You do not need to use Rhino's Package Manager for this installation method.

## 4. Verify the Installation

After installation:

1. Check that Rhino has completed the installation without reporting an error.
2. Open the ClimbFlow interface using the normal method provided by your installed version.
3. Confirm that the plugin interface appears and that its workflow steps are accessible.

If the installation or startup fails, see the troubleshooting section below.

## 5. Troubleshooting

### The package does not install

- Confirm that you are using Rhino 8 on Windows.
- Check that you downloaded the correct ClimbFlow `.yak` package.
- Try downloading the package again if the file may be incomplete.
- Read any error message displayed by Rhino.

### The plugin does not start correctly

- Check whether Rhino reported an installation or loading error.
- Restart Rhino if the installation process requested it.
- Record the error message before trying further changes.

### How to report a problem

When reporting an issue, please include:

- Your Rhino version
- A brief description of what you were doing
- The error message, if any
- A screenshot when useful

If you encounter an error in Rhino, you can also copy the relevant command history from the F2 command-history window and include it in your feedback.

Once the official feedback page is available, you can submit these details there.

## 6. Beta Notice

ClimbFlow is currently in beta. Some workflows may require manual review or adjustment.

Feedback from early users will help identify issues and guide future improvements.
